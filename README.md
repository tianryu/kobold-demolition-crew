# 狗头人拆迁队

单人 H5 拆解益智游戏。当前为 **1.5.0，50 张精编工地**，支持 PC 鼠标、键盘和手机横竖屏。

本次重做第20–50关的31张地图。每张图围绕共享承重、滚道、水火或跨层传递展开，包含4–8次关键拆除，验证路径为6–14工步。新机制接入同一工地的资源与保护问题，章节不再回到两三步的展示关。46关有无法靠重排撑木补救的拆序反例。没有按建筑编号开锁的前置条件。

| 关卡 | 新内容 |
| --- | --- |
| 26–30 | 可直接拆除的矿柱、地下矿室、叠柱与跨层坠落 |
| 31–35 | 坠落造成两次冲击的重锤，与重门、挡墙、火药组合 |
| 36–40 | 分左右低端的弹射跳板，滚石跨层、双跳板接力 |
| 41–45 | 跨层排水管、地下两层水渠、管道受损与干湿火药 |
| 46–50 | 遇水坍塌的朽木承台，承重、水流、重锤和滚石的组合 |

地图上 **红色靶标必须拆除，蓝绿盾牌必须保全，没有任务标记的物件可自行取舍**。标记为无编号图标和短箭头，直接指向所属物件；定位按钮会移镜头并闪亮对应物件。建筑耐久与HUD剩余总数仍保留。

提示只介绍新机制的效果和特点，不提供关卡解法，也不预选第一步。剩余工步常驻左上，选点时显示消耗1工步；未读过这条规则的旧玩家也会看到一次说明。规则可从目标面板主动回看。

## 本地试玩

需要 Node.js 20 或更新版本，运行游戏无需安装项目依赖。

```sh
npm run build
npm run dev -- dist
```

启动后访问 [本地试玩](http://127.0.0.1:4175/)。

先点作业点看预览，再按大按钮确认。鼠标悬停、Tab 焦点也可预览；空格确认，1/2 换工具，A/D 或方向键移动视野，Esc 暂停。手机可点选及拖动空白区域移动视野。触点至少 44 CSS 像素，右上留给平台退出按钮。

## 规则与存档

- 箭塔倒两格，钟楼倒三格；撑木吸收一次冲击，同一轮多次冲击分别计算。
- 挡墙截断同层冲击与水流；墙拆掉后，已有水域会按新缺口延伸。
- 承台、矿柱失去承重后，上层沿所在位置坠落。物件仍有其他承托时不会凭空坠落。
- 重锤落地打两次；滚石最远四格，碰第一件实物停止；正确方向的跳板将其送往高一层，最远三格。
- 火药桶爆炸两格，工坊三格；水塔出水三格，泉眼和排水管两格。湿火药不会爆炸，朽木支脚触水会失稳。
- 已交记录、历史最佳与收入保留；改版中的施工单在同一关重新布置，未改版现场继续接续。旧50关历史账本和第15关预算续接仍有效，重玩不重复领款。
- 第20关之后预算比验证最短解多两工步。只按真实保护损坏或实际工步归零判负，不以预测无解或没有后续动作提前判负。

## 激励广告

启动满一分钟后，从第2关起，已完成至少两步施工的玩家在失败结算可主动选择「看广告撤回一步」。完整观看后恢复最后一步之前的建筑、撑木和剩余工步。每局可用一次，两次领取至少间隔一分钟。直接重开和返回工棚始终可用。

TapTap 渠道构建时通过 `KOBOLD_REWARDED_AD_UNIT_ID` 传入本游戏的公开广告单元 ID，再执行 `npm run build`。普通网页构建留空，广告按钮仅在宿主与广告位均可用时出现。按 `onClose` 的 `isEnded === true` 结算，测试使用隔离的 SDK 夹具。真实播放需在本游戏广告开通后使用 TapTap 客户端验证。[TapTap 激励视频接口](https://developer.taptap.cn/minigameapidoc/dev/tutorial/open-capabilities/ad/rewarded-video-ad/)
